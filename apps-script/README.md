# 문의 폼 연결하기

사이트의 Contact 폼이 구글 시트에 기록되고 담당 메일로 알림이 가게 만드는 순서입니다.
전부 긍정님 구글 계정에서 하시는 작업이고, 10분이면 끝납니다.

## 1. 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다. 이름은 `맥플루 문의` 정도로.
2. 주소창의 URL에서 `/d/` 와 `/edit` 사이의 긴 문자열이 **시트 ID** 입니다. 복사해 둡니다.

   ```
   https://docs.google.com/spreadsheets/d/여기가_시트_ID/edit
   ```

시트 안에 탭을 미리 만들 필요는 없습니다. 첫 문의가 들어오면 `문의` 탭과 머리글이 자동으로 생깁니다.

## 2. 스크립트 붙이기

1. 그 시트에서 **확장 프로그램 → Apps Script**.
2. 기본으로 열린 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
3. 맨 위 세 값을 채웁니다.

   - `SHEET_ID` — 1번에서 복사한 값
   - `TOKEN` — `form-config.js` 에 들어 있는 값과 **글자 하나까지 똑같이**. 다르면 문의가 거부됩니다
   - `TO_BY_KIND` — 기본값 그대로 두시면 Creator는 cast@, Brand는 brand@ 로 갑니다

4. 저장(⌘S).

## 3. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴 → **웹 앱** 선택.
3. 설정:
   - 설명: `문의 수신기 v1`
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 이게 핵심입니다. `모든 사용자`가 아니면 사이트에서 호출이 막힙니다.
4. **배포** → 권한 요청이 뜨면 승인합니다. (본인 계정으로 시트를 쓰고 메일을 보내는 권한입니다.)
5. 나오는 **웹 앱 URL** 을 복사합니다. `https://script.google.com/macros/s/…/exec` 형태입니다.

> 처음 승인할 때 "이 앱은 확인되지 않았습니다" 경고가 나올 수 있습니다.
> 본인이 방금 만든 스크립트이니 **고급 → (프로젝트 이름)(으)로 이동** 을 눌러 진행하시면 됩니다.

## 4. 사이트에 값 넣기

`form-config.js` 를 열어 두 줄을 채우고 커밋하면 끝입니다.

```js
window.MACFLU_FORM = {
  endpoint: 'https://script.google.com/macros/s/…/exec',   // ← 3번에서 받은 URL
  token: 'mf_2026_kR7xQ2vL9pAe',                           // ← 이미 채워져 있음
};
```

토큰은 이미 넣어뒀으니 `endpoint` 한 줄만 채우면 됩니다.

## 5. 확인

1. 배포 URL을 브라우저에서 그냥 열어봅니다. `{"ok":true,"service":"macflu-contact"}` 가 보이면 살아있는 겁니다.
2. macflu.com/contact 에서 본인 이메일로 한 건 넣어봅니다.
3. 시트에 줄이 생기고, cast@ 로 메일이 오면 완료입니다.

## 알아두실 것

- **토큰은 비밀이 아닙니다.** 정적 사이트라 브라우저에서 보입니다. 지나가는 봇을 거르는 자물쇠 정도입니다. 진짜 방어는 허니팟(사람 눈에 안 보이는 칸)과 분당 20건 상한입니다.
- **메일은 하루 100통까지** 입니다(일반 지메일 계정 기준). 문의량으로는 넉넉합니다.
- **보내는 사람**은 스크립트를 배포한 계정이 됩니다. 받은 메일에 그대로 답장하면 문의한 분에게 갑니다(`replyTo` 설정해 뒀습니다).
- 전송이 실패하면 사이트가 "메일로 보내기" 버튼을 띄웁니다. 적은 내용이 그대로 메일 앱에 채워지므로 문의가 유실되지 않습니다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. URL은 그대로입니다.
